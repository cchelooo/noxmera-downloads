# Noxmera Launcher

Descargas oficiales para Windows x64. Versión estable: **0.1.9**.

- [Descargar instalador](https://github.com/cchelooo/noxmera-downloads/releases/download/v0.1.9/Noxmera-Setup-0.1.9-windows-x64.exe)
- [Descargar ZIP portable](https://github.com/cchelooo/noxmera-downloads/releases/download/v0.1.9/Noxmera-windows-x64.zip)
- [Notas de la versión](https://github.com/cchelooo/noxmera-downloads/releases/tag/v0.1.9)

El instalador conserva tus instancias y ajustes. Para usar el ZIP, extráelo y abre `Noxmera.exe`.
Si ya tienes Noxmera, puedes actualizar desde **Ajustes → General → Actualizador**, al cerrar o reiniciando el launcher.

La 0.1.9 añade Sync personal de JEI, REI y EMI para las versiones revisadas de Minecraft 26.2; logs exportables; publicadores OP, iconos y avisos de actualización en Global; y mejoras de fluidez en Skins y las barras de carga.

Para usar Global, inicia sesión con tu cuenta de Minecraft. Los jugadores no necesitan una cuenta de GitHub.

Las releases incluyen los metadatos firmados que verifica el actualizador y `SHA256SUMS.txt` para comprobar los archivos.
