# Noxmera Launcher

Noxmera es un launcher de Minecraft Java para Windows. Puedes administrar tus modpacks, reutilizar tus teclas y ajustes entre instancias e instalar instancias compartidas desde **Global**. Cada instancia mantiene su propia versión de Minecraft, mods y mundos.

## Descarga y primeros pasos

1. Abre la [última versión para Windows x64](https://github.com/cchelooo/noxmera-downloads/releases/latest). Elige el instalador `Noxmera-Setup` o extrae el [ZIP portable](https://github.com/cchelooo/noxmera-downloads/releases/latest/download/Noxmera-windows-x64.zip) y abre `Noxmera.exe`.
2. En **Ajustes → Cuentas**, añade tu cuenta de Microsoft con Minecraft Java.
3. Abre **Global** para instalar una instancia compartida, **Nueva instancia** para empezar de cero o **Importar** para traer un modpack que ya usas.

Si ya tienes Noxmera, puedes actualizarlo desde **Ajustes → General → Actualizador**.

## Global

**Global** reúne las instancias que publica el equipo de Noxmera y otros publicadores autorizados. Selecciona una instancia y pulsa **Descargar seleccionada**. Tu copia aparece en la biblioteca y queda vinculada a la publicación. Si hay una revisión nueva, Noxmera te avisa. Puedes descargar los cambios desde Global con **Pull changes**.

El equipo puede publicar mods, packs de recursos, configuraciones del modpack y un servidor por defecto. Tus mundos, tus cuentas y tus teclas se quedan en tu equipo.

**Noxmera SMP distribuirá su instancia por Global.** Cuando abra, podrás descargarla desde Global y encontrar el servidor en **Multijugador**. Para entrar a Noxmera SMP, registra tu nombre de Minecraft en **#whitelist** de Discord. Los pasos completos estarán en **#como-entrar**.

## Sincroniza tus teclas

1. En la barra lateral, abre **Sincronizar (Sync) → Ajustes de Minecraft → Atajos**. Configura tus teclas ahí o usa **Importar desde instancia** en Sync para traer ajustes de una instancia que ya configuraste.
2. Activa **Aplicar a instancias nuevas** y guarda tus cambios. Tus instancias nuevas y las que descargues de Global podrán usar ese perfil personal desde el primer arranque.
3. Para aplicar el perfil a una instancia que ya tienes, abre **Editar → Ajustes → General → Aplicar mi Sync** y confirma con Minecraft cerrado.

En Sync también puedes guardar ajustes y atajos compatibles de mods como Xaero, Litematica, JEI, REI y EMI. Sodium y Sodium Extra tienen sus propios paneles.

## Más herramientas

- **Catálogo.** Busca mods, modpacks, packs de recursos y shaders de Modrinth y CurseForge desde el launcher.
- **Importación.** Trae instancias de Prism Launcher o Modrinth App, o instala un archivo `.mrpack` o ZIP de CurseForge.
- **Compartir enlace.** Desde el menú de una instancia puedes crear un enlace válido durante dos horas. Tu amigo lo abre o lo pega en **Importar → Importar desde enlace** para instalar una copia independiente.
- **Editor de instancias.** Gestiona tus mods y mundos, crea copias de seguridad y revisa dependencias que falten.
- **Apariencia.** Personaliza la biblioteca e importa, exporta o edita temas en **Ajustes → Apariencia**.

Si algo falla, cuéntanos en **#ayuda-y-feedback** de Discord qué intentabas hacer y qué mensaje apareció. Las novedades están en las [notas de cada versión](https://github.com/cchelooo/noxmera-downloads/releases).
